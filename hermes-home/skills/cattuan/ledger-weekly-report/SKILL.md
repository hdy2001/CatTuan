# 记账周报

## 什么时候用
用户问「这周花了多少」「出个周报」，或者「记账管家」目标在周日做检查时。

## 步骤
1. 用 `ledger_query` 查本周（周一到今天）和上周（上周一到上周日）的账，type=expense。
2. 用 `ledger_memory` read 读预算和固定支出。
3. 计算：本周总支出、和上周相比的差额与百分比、分类前三、本月预算还剩多少（有预算时）。
4. 只算账本里有的数，不要估算没记的支出。

## 输出（最多 5 行）
- 本周支出 ¥X，比上周多/少 ¥Y（Z%）
- 花得最多：分类A ¥a、分类B ¥b、分类C ¥c
- 本月预算还剩 ¥R（没设预算就写「还没设预算，要不要定一个？」）
- 一条具体建议，例如「奶茶这周 5 杯 ¥80，下周少两杯就能省 ¥32」
- 发现疑似重复记账时单独列出来，问用户要不要删

用在目标检查里时：STATUS 写「本周支出 ¥X」；只有周日或超预算时才 NEW: yes。
