# 本地闪购/即时配送搜索

## When to Use
用户说「附近能闪购的」「30分钟能送到」「即时配送」「附近门店自提」「跑腿代买」等，且涉及具体商品（项链、礼物、药品、鲜花、食品等）。

## 适用场景
用户要在短时间内（30分钟–2小时）在附近拿到某样东西，需要找到支持闪送/即时配送/自提的店铺。

## 步骤
1. **确认区域**：任务里没写用户在哪（街道、商圈或区）时，结果里先说明需要用户补充位置，不要猜。
2. **使用工具**：调用 `web_search`，需要细节时用 `web_fetch` 读原文。
3. **搜全网**：用「区域名 + 商品名 + 闪送/即时配送」「区域 + 商场/购物中心 + 商品」「品牌名 + 区域 + 地址」「美团闪送 + 商品 + 城市」等组合搜，找附近店铺和用户实测分享。
4. **确认配送方式**：对找到的店铺，确认是否支持美团闪购/闪送/跑腿代买/到店自提。美团闪购覆盖珠宝、美妆、3C、鲜花等品类，30分钟送达，有保险保障。
5. **整理输出**：按「店名 · 地址 · 价格区间 · 款式/品牌 · 配送方式」列出选项，标注距离和预计送达时间。

## 搜索策略
- 区域关键词用街道名（如「望京」），不要用城市名（太宽）
- 商场名要具体（如「环贸新生活」「来福士」），不要只写「附近商场」
- 品牌名 + 区域名组合搜（如「施华洛世奇 朝阳区」）
- web_search 返回空结果时换关键词重试，连续 3 次空结果才放弃该角度

## 输出格式
先 1–2 句总结（哪个渠道最快、哪个选择性价比最高），然后列出 3–5 个具体选项，每个包含：店名、地址、价格区间、推荐款式、配送方式、预计时间。最后给一条具体建议（如「优先打开美团闪购搜项链，选附近支持即时配送的店」）。

## 陷阱
- web_search 可能连续返回空结果，这是服务波动，不是真的没有结果——换关键词重试，不要立刻放弃
- 搜到的经验帖可能是广告/带货，注意区分真实分享和营销内容
- 美团闪购的珠宝品类有保险保障，但贵重物品（黄金、钻石）建议到店自提
- 闪送/跑腿代买适合贵重物品，一对一配送更安全，但费用更高（通常 20–50 元起）
- 老城区、居民区可能没有大型商场，最近的选择可能在 2–3 公里外的商圈
