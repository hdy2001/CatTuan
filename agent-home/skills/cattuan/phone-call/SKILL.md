# 打电话

电话只有子 agent 能打（phone_call 工具）：打一通要 1–5 分钟。主 agent 负责问清楚、派出去、转述结果；子 agent 负责找电话和打。

## 派之前（主 agent）
1. **先分清只问还是要约**：只问不约（问有没有位、多少钱、几点关门）不报用户信息、不答应任何事；要约会报预约人、会替用户答应。替用户给家人朋友传话、送祝福也算只问不约，说了带什么话就直接派，不用问时间、称呼。
2. **缺信息先问，不派**：用 ask_user 出提问卡，一次问清缺的几项。必填：日期、时间、只问还是直接约；要约还要人数；美甲、美睫、美发、按摩、SPA 要项目；球场要时长和场地。用户说过的不再问；店还没定、电话没找到不算缺（子 agent 会去搜）。
3. **信息齐了直接派**：subagent 的 skills 写 ["phone-call"]，task 写清：打给谁（聊天里有的写「刚才那家」）、要办的事、日期时间人数项目、要问清的事（价格、付款方式）、碰到哪些情况不答应先回来问（只能约别的时间、要定金、要本人通话）；只问还是可以直接约（用户选了直接约就写「用户已确认，可以直接约」）。要问几家就写清问几家、每家问什么。
4. 派出去这一轮的回复开头带 📞，比如「📞 好，我打给悦榕轩问问，大概 1–5 分钟」，不用报对方号码。📞 和「我这就打」只在这一轮真派出去了时说；还要先问用户的，就只问，不说要打。

## 打的时候（子 agent）
1. **找电话**：任务或上面的对话里有电话就直接打，不用再核对；没有电话但有这家的链接（店铺页、地图页），先读链接找电话；都没有再 web_search 搜「店名 电话」。找不到电话就不打，报告里说清楚，别编号码。
2. **分清模式**：只问不约用 mode=ask，不报用户任何信息、不答应任何事；任务写了「用户已确认，可以直接约」才用 mode=book。
3. **要约时 details 带齐**：日期、时间、人数；美甲、美睫、美发、按摩、SPA 还要「项目」；球场要「时长」「场地」。缺了就别拨，结果里写清缺什么，让主 agent 去问用户，不要自己编。
4. **questions** 写要问清的事：用户没问也要问价格（单价、总价）和付款方式；要约的还要问位置保留多久、到店报什么。
5. **ask_user_if** 写碰到哪些情况不答应、回来问：只能约别的时间、要交定金或有最低消费、要本人通话、要换门店。用户要的时间对不上一律回来问，不要自己改时间。
6. 一次打一家，每家一次 phone_call。没有名单、要问几家时，先搜出 2–3 家评价好的、找到电话再挨个打。每个号码每天最多打 2 次（calls_left_today 是今天还能打几次）。
7. **看结果**：
   - dialed=false：没拨，result 是原因（没号码、不在外呼时间 8:00–20:00、这个号码今天打满了、平台拦了……）。
   - connected=false：打出去没接通。retry=soon 可以马上再打一次；later 这次别再打；tomorrow / no 今天别再打这个号码。
   - connected=true：看 summary、answers、booked、offer。need_user=true（店里给了别的时间、要定金、要本人通话）时绝不替用户答应，回来问。
   - outcome=refuse_ai：店里不接受 AI 来电，别再打，结果里写「需顾客本人拨打」。
8. **交回的结果**：先一句结论，再按电话列：打给谁、结果、关键信息（时间、价格、付款方式、保留多久、店里给的替代方案）。接通了的写清店里具体说了什么，不要只写「问到了」。没接通的写清原因和 retry。要用户决定的事单独写一句「需要用户决定：……」。不贴转写原文，不写 call_id 和工具名——通话组件会自动附在消息下面。

## 转述和跟进（主 agent）
- 第一段开头带一个 emoji，后面空一格：✅ 办成了（约上了、问到了）；⏸️ 要用户决定（店里给了别的时间、要定金、要本人通话），最后问一句怎么办；📞 没接通（没人接、占线、关机、不在服务区、语音信箱）；❌ 接通了但没办成（约满了、不接受 AI 电话、打错了），或者打不了（空号、停机、平台拦了、缺信息）。几家的结果按家说。不要说「通话记录」「转写」。
- 没接通、结果里 retry=later：建一个到点办一次的目标（create_goal，schedule 写 {"once": "半小时后的 HH:MM"}，外呼时间 8:00–20:00 以内），brief 写清再打给谁、电话号码、要办的事和原来的全部要求，并说明「这是自动重拨，只打这一次」；跟用户说几点会再打一次、打完告诉他。retry 是 tomorrow / no 的不要自动重拨，问一句要不要换一家或者明天再打。
- 用户对店里给的条件拍了板，用 steer_task 交给原来那个任务接着打。
- 打完以后用户问结果：照通话结果直接答，不要再派子 agent 重打。用户明确要再打一次才派。
